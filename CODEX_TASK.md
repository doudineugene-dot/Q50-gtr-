# Задача Codex

Источник требований: https://github.com/doudineugene-dot/Q50-gtr-/issues/11

С нуля выполнить только Phase 1: Android API 10, три русские страницы, оригинальный нативный рендер, DEMO/LIVE без смешивания, размерная диагностика/FPS, CI APK/EPK, тесты/изображения и документация.

Граница реализации: подключения к машине, исследование vendor Bluetooth, EcuTek и Air Lift относятся к следующим фазам. Не создаём протоколы или якобы реальные каналы. Действия управления автомобилем отсутствуют; manifest не запрашивает никаких permissions.

Структура, допущения и состояния данных описаны в `docs/architecture.md`. Следующий тест в автомобиле: `NEXT_TEST.md`, максимум пять действий. Точный список новых файлов: `codex-phase1/FILES_CREATED.txt`.
