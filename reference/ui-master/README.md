# Q50 GTR+ UI MASTER

Эти файлы получены непосредственно из утверждённого пользователем изображения.
Они НЕ сгенерированы заново нейросетью.

- MASTER_ENGINE_840x480.png — вкладка «ДВИГАТЕЛЬ»
- MASTER_FUEL_840x480.png — вкладка «ТОПЛИВО»
- MASTER_CHASSIS_840x480.png — вкладка «ШАССИ»
- MASTER_GEOMETRY.json — координаты исходных областей и преобразование в 840×480

Важно: исходный коллаж показывает три экрана с соотношением сторон, немного отличающимся от 840×480.
Поэтому экран вписан пропорционально в 840×480 без геометрического искажения. Небольшие поля являются
следствием сохранения пропорций исходного утверждённого изображения.

Для реализации Codex должен использовать MASTER PNG как pixel-reference, а не пытаться заново
интерпретировать исходный большой коллаж. Динамические значения, стрелки и активные состояния
реализуются кодом; графические декоративные ресурсы могут быть подготовлены из MASTER.
