ПРОЕКТ: doudineugene-dot/Q50-gtr-

Архив, приложенный к задаче, является окончательным визуальным эталоном Q50 GTR+.

ВАЖНО: НЕ ПЕРЕРИСОВЫВАЙ ДИЗАЙН С НУЛЯ И НЕ ДЕЛАЙ "ПОХОЖИЙ" UI.
Нужно использовать HYBRID-подход: статическая сложная OEM-графика берётся из MASTER, а все меняющиеся значения и стрелки рисуются программно поверх.

В архиве:
- ORIGINAL_APPROVED_MASTER.png — исходный утверждённый пользователем коллаж.
- MASTER_ENGINE_840x480.png
- MASTER_FUEL_840x480.png
- MASTER_CHASSIS_840x480.png
- MASTER_PREVIEW_ALL.png
- MASTER_GEOMETRY.json
- README.md

MASTER_*.png получены непосредственно из утверждённого изображения, а не сгенерированы заново.

ЦЕЛЬ
Сделать интерфейс визуально практически 1:1 с MASTER, но оставить динамическими данные автомобиля.

1. СОХРАНИ MASTER
Не изменяй исходные MASTER-файлы.
Положи их в reference/ui-master/.
Они нужны для сравнения и подготовки ресурсов.

2. HYBRID UI — ОСНОВНОЙ ПОДХОД
НЕ пытайся воспроизводить металлические кольца, glow, сложные тени и декоративную графику исключительно Canvas-примитивами.

Из MASTER подготовь статические runtime-ресурсы:
- engine_bg_clean.png
- fuel_bg_clean.png
- chassis_bg_clean.png

При необходимости также:
- dial_bezel.png
- dial_face_rpm.png
- dial_face_boost.png
- dial_face_lpfp.png
- dial_face_hpfp.png
- q50_rear.png
- suspension_strut.png
- необходимые статические иконки.

Разрешены PNG/WebP ресурсы.

НО запрещено просто положить полный MASTER_SCREEN как готовый фон со всеми цифрами и стрелками.

3. ЧТО УДАЛИТЬ ИЗ СТАТИЧЕСКОГО ФОНА
Из фоновых ресурсов убрать только элементы, которые должны меняться:

- стрелки приборов;
- центральные динамические цифровые значения;
- температуры;
- давления;
- AFR;
- fuel trim;
- boost target/actual;
- Knock Index;
- throttle;
- speed;
- AirLift pressure values;
- другие live/demo values.

Статическими МОГУТ остаться:
- металлические рамки;
- фон циферблатов;
- деления шкал;
- подписи шкал;
- названия RPM/BOOST/LPFP/HPFP;
- единицы измерения возле шкал;
- красные зоны;
- декоративные glow/тени;
- рамки карточек;
- подписи карточек;
- иконки;
- верхняя и нижняя декоративная панель;
- Q50 на вкладке ШАССИ;
- стойки пневмоподвески.

4. НЕ УДАЛЯЙ ЦИФРЫ ШКАЛЫ
Цифры 0–8 на RPM, -1.0…2.0 на BOOST, 0–10 на LPFP и 0–250 на HPFP являются частью шкалы и могут оставаться на статическом фоне.

Убирать нужно ДИНАМИЧЕСКИЕ значения, а не маркировку шкал.

5. ДИНАМИЧЕСКИЙ СЛОЙ
Canvas поверх фона должен рисовать:
- стрелки;
- ступень/передачу при необходимости;
- цифровые значения;
- единицы рядом с динамическими значениями, если это нужно для точного совпадения;
- активное состояние вкладки, если оно должно переключаться;
- реальные данные DataHub.

Координаты должны быть сняты непосредственно с MASTER.

6. ШРИФТ
Подбери максимально близкий узкий штатный шрифт.
Не утверждай, что это оригинальный proprietary Infiniti font, если его нет.

Для каждого динамического текста подбери:
- Typeface
- textSize
- alignment
- baseline
- letter spacing, если API позволяет
так, чтобы совпадение с MASTER было максимальным.

7. СТРЕЛКИ
Стрелки должны рисоваться отдельно поверх фонового циферблата.
Центр вращения, длина, ширина и форма берутся с MASTER.
Угол рассчитывается математически из значения.

RPM: 0–8 x1000
BOOST: -1.0…2.0 bar
LPFP: 0–10 bar
HPFP: 0–250 bar

LPFP сейчас не логируется текущей конфигурацией EcuTek.
Не показывай выдуманное live-значение.
При отсутствии данных отображай аккуратное состояние "—" / "НЕТ ДАННЫХ", сохраняя сам прибор.

Turbo Speed не добавлять.
