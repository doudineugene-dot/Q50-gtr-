# EcuTek на этом ГУ: закрыто

Итог долгой разведки. Записано, чтобы к вопросу не возвращались.

## Вывод

**Параметры уровня ECU на штатном InTouch DCU этого автомобиля получить
нельзя ничем.** Не «пока не разобран протокол EcuTek», а физически: до
адаптера нечем дотянуться.

Это касается наддува (факт и цель), AFR по банкам, Knock Index по
цилиндрам 1–6, коррекции по детонации, угла опережения, ТНВД и коррекций
топлива STFT/LTFT.

## Чем доказано

**Bluetooth отсутствует в Android-слое ГУ.** Снято на устройстве, шесть
независимых проверок:

```
API 10, публичный BLE API с API 18 -> BLE НЕДОСТУПЕН
hasSystemFeature(android.hardware.bluetooth) = false
getSystemService("bluetooth") = null
[service list] совпадений с "bluetooth" нет
[getprop] совпадений с "bluetooth" нет
getDefaultAdapter из главного потока: null
getDefaultAdapter из фонового потока: null
```

Каталоги `/sys/class/bluetooth/`, `/data/misc/bluetoothd/` присутствуют —
это остатки базового образа AOSP, стек в них не поднят. Bluetooth
автомобиля (имя INFINITI, телефония и аудио) работает, но живёт на
отдельном модуле вне Android.

**Сети, доступной извне, тоже нет:**

```
/sys/class/net: audio0 lo
```

`audio0` — внутренняя шина к аудио-подсистеме, адрес `169.254.11.1`
link-local. `lo` — петля. Ни `wlan`, ни `eth`, ни `usb0`.

**USB-адаптер не спасает:** Android USB Host API появился с API 12, здесь
API 10; и даже будь он, потребовался бы Bluetooth-стек, которого нет.

## Что это значит для материалов, которые раньше запрашивались

`btsnoop_hci.log` и APK приложения ECU Connect больше **не нужны**. Они
дали бы протокол, но применить его на этом ГУ не к чему: нет транспорта.

Сам адаптер EVI-6087 при этом, судя по признакам, в исполнении BLE
(ревизия R9, отказ в классическом сопряжении, подсказка системы про
приложение) — см. `docs/ECUTEK-EVI-6087.md`. Для итога это уже неважно.

## Что остаётся рабочим

Штатная шина через `SensorManager` (вендор Ygomi): 42 сигнала, каталог в
`docs/CAN-SENSORS-VR30DDTT.md`. Из них сейчас привязано девять: обороты
(восстановленные из мощности и момента), скорость, температура
охлаждающей жидкости и масла, давление масла, момент, мощность, селектор
передач, педаль газа.

Непривязанными остаются живые и полезные: давление во всех четырёх шинах,
расход мгновенный и средний, запас хода, угол руля, продольное и
поперечное ускорение, положение педали тормоза, стояночный тормоз,
одометр.

## Код, который остаётся в проекте

`EcuTekBluetoothProbe`, `EcuTekLiveSource`, `EcuTekRawLog`,
`BridgeSource` — оставлены. Они верны, покрыты документацией и
заработают без правок, если данные однажды пойдут с другого устройства.
На этом ГУ они молчат, и приборы честно показывают прочерк.
