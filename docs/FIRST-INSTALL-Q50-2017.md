# Установка тестовой сборки Q50 GTR+ v0.7-live-test на InTouch / DCU Gen1

Это **тестовая сборка с подключением к данным машины**, а не релиз. Визуал
утверждён и не менялся. Процедура live-теста — в `docs/VEHICLE-LIVE-TEST.md`,
здесь только установка. На
головном устройстве сборка ещё не запускалась, поэтому Release не публикуется,
пока она не отработает в машине.

Порядок тот же, что в проекте
[doudineugene-dot/q50](https://github.com/doudineugene-dot/q50), где тем же
сертификатом OBU уже ставилось своё приложение: штатный путь AppManager + USB.

**Прошивку DCU не трогаем.**

## BEFORE INSTALL

Файл берётся из артефакта сборки, а не из релиза:

| | |
|---|---|
| Артефакт | `q50gtr-0.7.NN` |
| Файл внутри | `q50gtr-0.7.NN.epk` |

**Имя файла у каждой сборки своё** — `NN` это номер прогона CI.
Переименовывать руками не нужно: файл с уже виденным именем AppManager в
списке не показывает, а уникальное имя эту проблему снимает.

Имя намеренно короткое. Пакеты, которые на этом ГУ реально ставились
(`q50dash-1.1.epk`, `q50info-1.8.epk`), — по 15 символов. Вариант на 35
символов AppManager не увидел вовсе: «No app file found». Форму держим
близкой к проверенной.

Контрольную сумму сверяйте с файлом `.epk.sha256` — он лежит в том
же архиве и записан самой сборкой. Отдельно её здесь не дублирую: цифра,
переписанная руками, проверкой быть перестаёт.

В архиве также `signature.txt`, `badging.txt`, `epk-info.txt` и
`BUILD-PROVENANCE.txt` — там видно, чем именно собрано и чем подписано.

Что уже проверено автоматически и переспрашивать не нужно: `minSdk 9`,
`targetSdk 10`, подпись v1 (JAR), v2/v3 выключены, нативного кода нет,
структура контейнера. Нативных библиотек в пакете нет вообще, поэтому
архитектура ГУ значения не имеет.

## USB PREPARATION

1. Файловая система флешки — **FAT32**.
2. `.epk` положить в **корень** флешки, не в подпапку.
3. Имя файла не менять: оно уже уникально для этой сборки.
4. **Старые `.epk` с флешки удалить.** Иначе в списке будет несколько похожих
   имён, и легко поставить прошлую сборку вместо новой.

«Неизвестные источники» включать **не нужно**: для `.epk` это требование не
действует.

## INSTALL

1. Вставить флешку в USB-порт машины.
2. Открыть на ГУ **AppManager** (`com.connexis.appsmanager`).
3. Найти в списке файл этой сборки (по номеру `bNN`) и запустить установку.

Если уже стоит v0.6 или прошлая тестовая — подпись и package те же, обновление
встаёт поверх. Релизы до v0.6 подписывались одноразовым ключом, их нужно
удалить.

`versionCode` у тестовых сборок намеренно остаётся 7: если поднимать его на
каждую сборку, потом не встанет production-релиз с меньшим номером.

## EXPECTED RESULT

- AppManager видит файл в списке — контейнер распознан и сертификат OBU подошёл.
- После установки в меню приложений появляется **Q50 GTR+**.
- При запуске — приборная панель с тремя вкладками: ДВИГАТЕЛЬ, ТОПЛИВО, ШАССИ.
- В верхней полосе горит **DEMO**: реальных данных пока нет, это ожидаемо.
  Отдельных бейджей на приборах и карточках нет — отметка одна.
- LPFP показывает «—» и «НЕТ ДАННЫХ»: канал не логируется текущей
  конфигурацией EcuTek, и правдоподобное число там было бы выдумкой.
- В кружке селектора передач прочерк, а не буква: передача отдельным каналом
  не приходит.
- Вкладки переключаются касанием и горизонтальным свайпом.

### Про чёрные поля по краям

Утверждённый эталон нарисован в пропорции примерно 1.14:1, а экран ГУ шире
(840×480 или, по данным проекта q50, 800×480 — это 1.67:1). Растягивать
картинку по горизонтали нельзя: круглые приборы стали бы овальными. Поэтому
кадр вписывается целиком и центрируется.

**На экране будут чёрные поля слева и справа, примерно по 145 px, и тонкие
полосы сверху и снизу.** Это не дефект установки и не ошибка отрисовки — это
прямое следствие пропорций утверждённого эталона. Приборы при этом остаются
круглыми: проверено рендером в 800×480, разброс радиуса безеля 1.6 px.

## IF EPK IS NOT DETECTED

Важно различать две надписи:

* **«No USB device»** — ГУ не смонтировало накопитель. Дело во флешке.
* **«No app file found»** — накопитель прочитан, но установочного файла на нём
  не нашлось. Дело в файле.

### «No app file found»

1. **Скачанный архив не распакован.** GitHub отдаёт `.zip`. На флешке должен
   лежать `.epk`, а не `.zip` и не папка с ним внутри.
2. **Скрытые расширения.** Windows по умолчанию их прячет, и файл может на
   самом деле называться `...epk.zip`. Включите показ расширений и проверьте.
3. **Файл в подпапке.** Нужен корень флешки.
4. **Слишком длинное имя.** Проверено: 35 символов ГУ не показывает, 15–21
   показывает. Сборка теперь сама даёт короткое имя.

### «No USB device»

1. **Файловая система.** Не FAT32 (exFAT, NTFS) — ГУ флешку не смонтирует.
2. **Порт.** В машине несколько USB-разъёмов; не все монтируются для данных.
3. **Сама флешка.** Попробовать другую, меньшего объёма.
4. **Целостность файла.** Сверить SHA-256 — обрыв скачивания даёт файл
   нужного вида, но битый.

Только когда файл заведомо виден — переходить к следующему разделу.

## IF EPK IS DETECTED BUT INSTALL FAILS

Важно, на чём именно остановилось:

- **Ошибка при распаковке контейнера** — сертификат OBU в
  `keys/obu_cert.pem` не парный закрытому ключу в вашей прошивке. Лечится
  заменой сертификата на снятый со своего ГУ (`keys/README.md`), а не
  пересборкой APK.
- **Ошибка при установке APK** — контейнер приняли, дело в самом пакете.
  Запишите текст ошибки: `INSTALL_FAILED_OLDER_SDK`,
  `INSTALL_FAILED_UPDATE_INCOMPATIBLE` и подобные указывают на причину.

## IF APP INSTALLS BUT DOES NOT START

1. Проверить, что приложение появилось в списке приложений.
2. Если вылетает сразу — нужен `logcat` с ГУ (на устройстве есть root и
   busybox): строки с `com.q50gtr.plus` покажут причину.
3. **Если фон не появился, а цифры и стрелки есть** — не прочитались растры
   из `res/drawable-nodpi`. Это отдельный класс ошибки, важно его различить:
   снимите фото, по нему будет видно сразу.
4. Если чёрный экран целиком — снять фото: это вопрос отрисовки, не установки.

## ROLLBACK

Приложение не трогает систему: обычный пользовательский пакет без нативного
кода и без записи в системные разделы.

- Удалить через штатное меню приложений ГУ.
- Прошивка, системные разделы и настройки не изменяются, откатывать нечего.
- Физически достаточно вынуть флешку: ничего не остаётся запущенным.
