# Первая установка Q50 GTR+ v0.6 на InTouch / DCU Gen1

Составлено по материалам проекта
[doudineugene-dot/q50](https://github.com/doudineugene-dot/q50), где тем же
сертификатом OBU уже ставилось своё приложение. Ничего недокументированного
здесь нет: только штатный путь AppManager + USB.

**Прошивку DCU не трогаем.** На первом тесте — только штатная установка.

## BEFORE INSTALL

Сверьте файл, который повезёте в машину:

| | |
|---|---|
| Файл | `Q50-GTR-Plus-v0.6.epk` |
| Размер | 21 088 байт |
| SHA-256 | `3f1ac3c339436aaa45cdb3d4ef7be4917de6f9d2383f6d154049f7c878ba1748` |

Берите ассет из [релиза v0.6](https://github.com/doudineugene-dot/Q50-gtr-/releases/tag/v0.6),
не пересобранный локально: подпись и контейнер проверялись именно для него.

Что уже проверено и переспрашивать не нужно: `minSdk 9`, `targetSdk 10`,
подпись v1 (JAR), отсутствие нативного кода, структура контейнера.

Нативных библиотек в пакете нет вообще, поэтому архитектура ГУ (по данным
проекта — x86) значения не имеет.

## USB PREPARATION

1. Файловая система флешки — **FAT32**.
2. `Q50-GTR-Plus-v0.6.epk` положить в **корень** флешки, не в подпапку.
3. Имя файла не менять.
4. Лишние `.epk` с флешки убрать, чтобы не выбрать чужой пакет.

«Неизвестные источники» включать **не нужно**: для `.epk` это требование не
действует.

## INSTALL

1. Вставить флешку в USB-порт машины.
2. Открыть на ГУ **AppManager** (`com.connexis.appsmanager`).
3. Найти в списке `Q50-GTR-Plus-v0.6.epk` и запустить установку.

## EXPECTED RESULT

- AppManager видит файл в списке — значит контейнер распознан и сертификат OBU
  подошёл.
- После установки в меню приложений появляется **Q50 GTR+**.
- При запуске — тёмная приборная панель с тремя вкладками: ДВИГАТЕЛЬ,
  ТОПЛИВО, ШАССИ.
- Все значения помечены бейджем **DEMO**: реальных данных пока нет, это
  ожидаемо. LPFP показывается как «НЕТ ДАННЫХ» — он не логируется.
- Вкладки переключаются касанием и горизонтальным свайпом.

### Про пропорции экрана

Интерфейс нарисован в сетке 840×480 и растягивается на весь экран. По данным
проекта q50 экран ГУ — **800×480**, поэтому картинка будет сжата по горизонтали
примерно на 5%: круглые шкалы станут слегка овальными. Это ожидаемо и не
является дефектом установки.

## IF EPK IS NOT DETECTED

Если AppManager пишет «No USB device» или не показывает файл — проверяйте по
порядку, это самый частый источник ошибок:

1. **Файловая система.** Не FAT32 (exFAT, NTFS) — ГУ флешку не смонтирует.
2. **Расположение.** Файл должен лежать в корне, а не в папке.
3. **Порт.** В машине несколько USB-разъёмов; не все монтируются для данных.
4. **Сама флешка.** Попробовать другую, меньшего объёма.
5. **Целостность файла.** Сверить SHA-256 ещё раз — обрыв скачивания даёт
   файл нужного вида, но битый.

Только когда файл заведомо виден — переходить к следующему разделу.

## IF EPK IS DETECTED BUT INSTALL FAILS

Файл распознан, но установка не проходит. Это разные причины, и важно, на чём
именно остановилось:

- **Ошибка при распаковке контейнера** — значит сертификат OBU в
  `keys/obu_cert.pem` не парный закрытому ключу в вашей прошивке. Лечится
  заменой сертификата на снятый со своего ГУ (`keys/README.md`), а не
  пересборкой APK.
- **Ошибка при установке APK** — контейнер приняли, дело в самом пакете.
  Запишите текст ошибки: `INSTALL_FAILED_OLDER_SDK`,
  `INSTALL_FAILED_UPDATE_INCOMPATIBLE` и подобные указывают на конкретную
  причину.
- **Уже стоит версия с другой подписью** — удалить прежнюю и поставить заново.
  Релизы до v0.6 подписывались одноразовым ключом, поэтому обновление поверх
  них не встанет.

## IF APP INSTALLS BUT DOES NOT START

1. Проверить, что приложение появилось в списке приложений.
2. Если вылетает сразу — нужен `logcat` с ГУ (на устройстве есть root и
   busybox): строки с `com.q50gtr.plus` покажут причину.
3. Если открывается чёрный экран без гаджетов — снять фото экрана: это уже
   вопрос отрисовки, а не установки.

## ROLLBACK

Приложение не трогает систему: это обычный пользовательский пакет без
нативного кода и без записи в системные разделы.

- Удалить через штатное меню приложений ГУ.
- Прошивка, системные разделы и настройки не изменяются, откатывать нечего.
- Физически достаточно вынуть флешку: ничего не остаётся запущенным.
