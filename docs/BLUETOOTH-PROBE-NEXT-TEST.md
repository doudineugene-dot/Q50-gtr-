# Следующая проверка штатного Bluetooth — максимум пять действий

1. На стоящем автомобиле установить отдельный **Q50 EcuTek Probe** из
   `Q50-Codex-EcuTek-Probe.epk` (пакет `ru.q50.ecutekprobe`) через AppManager.
   Если предлагается заменить рабочее приложение — остановиться и записать экран.
2. Оставить EVI-BT R9 запитанным, отключить от него ECU Connect и VR30 DASH;
   открыть пробник и нажать **НАЧАТЬ 90 С**. Никаких внешних Bluetooth-адаптеров.
3. Через 15 секунд открыть VR30 DASH 0.5.4 и подключить его к EVI штатным Bluetooth;
   оставить живой RPM примерно на 45 секунд, отметить время и видимый RPM.
4. Около 60-й секунды отключить EVI в VR30 DASH или снять питание EVI;
   вернуться в пробник и дождаться **Готово**. Поля RPM/Boost пробника в этой
   диагностической версии остаются «НЕТ ДАННЫХ».
5. Нажать **ЭКСПОРТ НА USB** и сохранить показанный `run-*.zip` вместе с временами
   соединения/отключения. Если USB не виден — сохранить показанный архив из
   `Q50-EcuTek-Probe` общей памяти; если и она недоступна, сфотографировать ошибку
   и использовать уже имеющийся host shell для выгрузки приватного отчёта.

Тест устанавливает транспорт/права/библиотеки, а не подтверждает EcuTek RPM.
В архиве нужны `native.txt`, `hci-packets.jsonl`, `inventory-*.txt`,
`processes-*.txt`, `packages.txt`, `COMPLETE.txt`. `EPERM/EACCES` требует host
capture с уже доступными правами; `EAFNOSUPPORT` в Android требует сравнения
с host Linux, а не вывода о невозможности штатного Bluetooth. Нет захвата —
нужен легально полученный APK/EPK VR30 DASH для статического анализа.
