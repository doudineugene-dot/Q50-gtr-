# UI MASTER SPEC — Q50 GTR+

Снято измерением master reference, а не на глаз. Все координаты приведены к
экрану **840 × 480**.

## Исходные измерения эталона

Панель одного экрана на master reference: **533 × 473 px**.

| Элемент | Эталон (локально) |
|---|---|
| верхняя полоса | y 0..42 |
| левый прибор | cx 137, cy 169, r 122 |
| правый прибор | cx 393, cy 177, r 122 |
| карточки | y 295..385 (h 90), x 9..129 / 136..261 / 268..394 / 401..523 |
| нижняя навигация | y 419..473 (h 54) |
| вкладки | x 34..517, три равные |

## Важное расхождение пропорций

Эталон имеет соотношение **533:473 = 1.13:1**, экран головного устройства —
**840:480 = 1.75:1**. Буквальный перенос невозможен: растягивание по
горизонтали в 1.55 раза превратило бы круглые приборы в эллипсы.

Поэтому масштаб взят **по высоте** (k = 480/473 = 1.0148), пропорции элементов
сохранены, а избыток ширины ушёл в поля и в промежуток между приборами.
Вертикальная раскладка совпадает с эталоном с точностью до пикселя.

## Шрифт

Оригинальный шрифт Infiniti недоступен. Используется системный condensed
sans-serif (`sans-serif-condensed`), на Android 2.3 подставляется обычный
sans-serif. Узкие высокие цифры эталона воспроизводятся приближённо.
