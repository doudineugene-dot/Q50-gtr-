# Карта данных InTouch

| Канал | Состояние новой реализации | Доказательство / следующий шаг |
|---|---|---|
| RPM | NOT FOUND — адаптер ещё не реализован | Владелец в issue #11 сообщил 659/2202 rpm в старом тесте; повторить с новым источником в Phase 2 |
| speed | NOT FOUND | Нужны vendor API и лог с движением |
| coolant | NOT FOUND | Нужен реальный изменяющийся канал |
| throttle | NOT FOUND | Нужен лог с педалью |
| oil temp / oil pressure | NOT FOUND | Не считать зарегистрированный sensor доказательством |
| gear | NOT FOUND | Нужен лог с выбором передач |
| voltage / outside / intake | NOT FOUND | Нужны единицы, диапазон, timestamp и независимая сверка |
| LPFP pressure | NOT FOUND | Всегда UNAVAILABLE до доказанного pressure channel |

NOT FOUND здесь означает «в новой реализации источник пока не найден/не подключён», а не невозможность существования канала на DCU. SUPPORTED/UNSTABLE назначаются только после получения лога и проверки на машине. DEMO-значения не являются доказательствами.
