# keys/

## `obu_cert.pem` — публичный сертификат OBU

Нужен, чтобы собрать загружаемый `.epk`: `epktool.py build` заворачивает
`dataKey` шифрованием RSA на этот **открытый** ключ, а ГУ разворачивает его
своим закрытым ключом из прошивки. Для сборки достаточно публичной половины —
она здесь и лежит.

**Происхождение.** Сертификат взят из открытого проекта
[qazwsd147/appgarage-dash](https://github.com/qazwsd147/appgarage-dash)
(лицензия MIT, © bugjosh), куда он включён автором. Это флотовый/типовой
сертификат `CN=tt18002`, издатель `IT5.YGOMI.COM CA`, RSA-1024 — он поставляется
в прошивке InTouch и **не является ничьим секретом**, закрытого ключа в нём нет.

**Важно про совместимость.** `.epk`, собранный этим сертификатом, загрузится
только на ГУ, чья прошивка несёт **парный** закрытый ключ OBU. По данным
исходного проекта это InTouch на Android 2.3.7 (API 10, x86), проверено на
2018 Q60 Red Sport. На других годах/регионах ключ может не подойти.

**Если у вас другой ГУ.** Извлечь публичный сертификат из своего `obu.p12`
(лежит в прошивке вашего устройства) и заменить им этот файл:

```bash
openssl pkcs12 -in obu.p12 -passin pass:<пароль> -legacy -nokeys -clcerts > keys/obu_cert.pem
```

Только для машины, которой вы владеете.

## Постоянный ключ подписи APK

Не путать с сертификатом OBU выше: тот нужен для упаковки `.epk`, этот — для
подписи самого APK.

По умолчанию сборка генерирует ключ подписи на раннере и выбрасывает его —
`SIGNING_MODE=temporary`. Для проверок этого достаточно, но обновить такую
сборку поверх установленной нельзя: у следующей будет другой сертификат, и
Android откажется ставить обновление.

Поэтому публикация release разрешена **только** при `SIGNING_MODE=persistent`,
то есть когда ключ приходит из секретов репозитория. Заводится один раз:

```bash
keytool -genkeypair -noprompt \
    -keystore q50gtr.keystore \
    -alias q50gtr \
    -storepass '<пароль>' -keypass '<пароль>' \
    -keyalg RSA -keysize 2048 -sigalg SHA1withRSA \
    -validity 10000 \
    -dname "CN=Q50 GTR Plus, OU=Head Unit, O=Personal, L=-, ST=-, C=RU"

base64 -w0 q50gtr.keystore   # это значение идёт в секрет
```

`SHA1withRSA` — не прихоть: Android 2.3 не знает более новых дайджестов в
схеме v1.

Дальше в Settings → Secrets and variables → Actions завести три секрета:

| Секрет | Значение |
|---|---|
| `Q50_KEYSTORE_BASE64` | вывод `base64 -w0 q50gtr.keystore` |
| `Q50_KEY_ALIAS` | `q50gtr` |
| `Q50_KEY_PASS` | пароль, заданный выше |

Сам `q50gtr.keystore` хранить у себя и **не коммитить**: ключ, попавший в
публичный репозиторий, перестаёт что-либо защищать, и восстановить контроль
над уже установленными копиями приложения будет нечем.

После первой сборки с постоянным ключом сборка напечатает
`Signer certificate SHA-256`. Эту строку нужно записать в
`release-signing-cert.sha256` и закоммитить — дальше каждая публикация
сверяется с ней и падает, если сертификат сменился.
