## Зачем

На Android 2.3 нет ни `sans-serif-condensed`, ни светлого начертания:
`Typeface.create` молча возвращает обычный Droid Sans. Его цифры заметно
жирнее, чем на утверждённом эталоне, где крупные значения тонкие.

Эта копия Lato содержит латиницу, цифры и знаки, но **не содержит кириллицы**
(295 глифов). Это не мешает: на эталоне кириллические подписи как раз
нормального веса, а тонкие — именно цифры и латинские названия приборов.
`Theme` выбирает начертание по содержимому строки и для кириллицы берёт
системный шрифт.
